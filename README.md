# Jawaban Refleksi
1. Karena kamera A-Frame secara default menghadap ke arah sumbu Z negatif. Jadi, objek dengan nilai Z negatif berada di depan kamera sehingga bisa terlihat oleh pengguna. kalau Z-nya positif, objek berada di belakang kamera sehingga tidak terlihat.
2. Karena browser memerlukan koneksi yang aman untuk menjalankan fitur VR dan AR. Hal ini bertujuan melindungi privasi pengguna dan mencegah akses perangkat tanpa izin. Localhost juga dianggap aman karena halamannya berasal dari komputer sendiri, jadi bisa dipakai untuk pengembangan dan pengujian secara lokal.
3. WebXR Device Api menghubungkan aplikasi web dengan perangkat VR atau AR, Three.js digunakan untuk membuat dan menampilkan grafis 3D di browser, sedangkan A-Frame mempermudah pembuatan scene 3D dan VR menggunakan elemen HTML.
